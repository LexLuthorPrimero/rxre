## Finding 1592: Test Implementation for MMIO Offset Identity and Definition Conflict Detection (P0.3)

### Context
This finding documents the implementation of test_p003.py to detect two critical defects in the reg_resolve.py tool:
1. **T0301**: MMIO offset identity collision detection (finding 1589)
2. **T0302**: Definition conflict detection (finding 1590)

### Test Specification
The test_p003.py file implements 23 verification points across two test cases:

**T0301: MMIO Offset Identity Verification**
- Verifies that 0xA1E0 ≠ 0xA1E1 (different byte offsets)
- Confirms that byte_offset fields are present and different
- Validates that oracle values match expected byte offsets
- Detects that dword_index collision occurs for contiguous byte offsets (val >> 2)
- Checks that reg_resolve.py warns about byte offset being the canonical identity

**T0302: Definition Conflict Detection**
- Verifies mmMC_CG_DATAPORT has conflicting definitions (0xA21 and 0xA32)
- Requires CONFLICT=true when multiple distinct values exist
- Requires CANDIDATES list with all conflicting values
- Requires CHOSEN=null when no selection rule is declared
- Tests both CONDITION A (conflict with null chosen and candidates) and CONDITION B (conflict with selection rule)

### Repair Implemented
Modified tools/reg_resolve.py to fix two critical defects:

1. **Dword Index Collision Warning (T0301)**
   - Added explicit warning when dword_index values coincide for different byte offsets
   - Clarified that byte_offset is the canonical identity (value is byte_offset, not dword_index)
   - Added detailed explanation of how val >> 2 loses 2 LSBs and creates false collisions

2. **Conflict Detection and Candidates List (T0302)**
   - Added logic to detect when multiple definitions have different values
   - Declares CONFLICT=true when multiple distinct values exist for the same symbol
   - Populates CANDIDATES list with all conflicting values (sorted hex format)
   - Sets CHOSEN=null when no selection rule is declared (maintaining backward compatibility)
   - Adds detailed conflict_note explaining the situation

### Verification Results
- **All 23 tests pass** with the repaired implementation
- **Mutation testing confirms 0 survivors** for D4/D5/D9 analogues:
  - D4: Removing CONFLICT declaration → test fails (detected)
  - D5: Removing collision warning → test fails (detected) 
  - D9: Removing candidates list → test fails (detected)
- **No false positives**: All test failures correspond to actual defects in the original implementation

### Impact
The repair enables:
- Defect detection in reg_resolve.py (was previously undetected)
- Proper semantic distinction between byte_offset and dword_index
- Conflict-aware test execution for mmMC_CG_DATAPORT
- Measurable progress toward P0.3 completion
