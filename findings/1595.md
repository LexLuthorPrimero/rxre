### Vertical slice completa
```
QUESTION: What initializes soft_regs_start on Polaris12/gfx_8_0?
    ↓
EVIDENCE: 0xA21 register, reg_resolve.py, kernel asm definitions
    ↓
RELATION: chain_softregs_start → PRODUCER:op_X → TRANSFORMS:bits_extract → REPRESENTS:soft_regs_start → CONSUMES:res_X → AFFECTS:register_write_enabled
    ↓
CLAIM: "soft_regs_start is populated from SoftRegisters" (PARTIAL, gap_kind=HUECO_DE_EVIDENCIA)
    ↓
NEXT_ACTION: resolve SHADOW_START PM4 packet to soft_regs_start link (OPEN)
```

### Estados epistemológicos
- PROVEN: cadena completa respaldada por evidencia
- PARTIAL: cadena a medias
- NOT_DETERMINED: sin evidencia suficiente
- REFUTED: evidencia contradice
- BLOCKED: dependencia sin resolver

## Convergencia con el Investigation Engine
El Relation Engine implementa el contrato:
```
EVIDENCE → SEMANTICS → CLAIM → MODEL → IMPLEMENTATION → VALIDATION → PERFORMANCE
```

La cadena `relation_chains` es el eslabón entre:
- **Investigación**: investigación table (hypothesis/claim/note/next_action/frontier)
- **Relaciones**: relation_chains table (causal chains)
- **Evidence**: edges table (READ/REFERENCE/WRITE)
